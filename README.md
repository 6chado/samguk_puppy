# 삼국지 멍냥이 키우기 (Godot 4.7)

삼국지 장수를 강아지(무장) / 고양이(책사)로 데려와서 5~6분 만에 어른까지 키우는 모바일 세로형 육성 게임.

## 실행
1. Godot 4.7에서 `project.godot` 열기 (렌더러: Compatibility, 720×1280 세로)
2. 폰트: `assets/fonts/main.ttf` (온글잎 박다현체). `♤ ♧`를 쓰면 고양이 얼굴이 나옴
   - 폰트에 없는 글자는 화면에 안 나옴 (시스템 폰트 대체를 꺼 둠 → 멈춤 방지)
3. F5로 실행

## 화면
| 화면 | 내용 |
|---|---|
| 홈 | 마지막으로 키운 멍냥이, 뽑기권 수, 도감 수 / 키우러 가기 · 뽑기 · 도감 |
| 키우러 가기 | 데리고 있는 멍냥이를 진영 탭(촉·위·오·스페셜)별로. 맨 위 금테 = 주군 |
| 도감 | 모은 멍냥이는 키운 단계까지의 그림, 모르는 애는 ???. 누르면 새끼 › 청년 › 어른 그림 |
| 뽑기 | 뽑기 기계 + 손잡이. 아직 없는 멍냥이 중 똑같은 확률로 한 마리 |
| 키우기 | 밥 4종 · 전투(책사는 책략 내기) · 가방 · 잠자기 · 쓰다듬기 · 관계도(하트) |

## 게임 규칙
- 처음엔 유비 · 조조 · 손권 + **뽑기권 3장**으로 시작
- 한 마리를 어른까지 키우면 **뽑기권 3장** (마리당 한 번) → 13마리 키우면 45마리 다 모음 (약 1시간 10분)
- 4단계 성장: 새끼강아지 › 개초딩 › 개청소년 › 어른강아지 (고양이: 새끼고양이 › 캣초딩 › 캣청년 › 어른고양이)
- 밥 한 입 / 전투마다 피로도 → 꽉 차면 잠자기만 가능, 자고 나면 0
- 쓰다듬기: 강아지는 피로도가 조금 풀리고, 고양이는 오히려 피곤해함 (5번 연속이면 화냄)
- 어른이 되면 성장 대신 친밀도가 오름

### 희귀템 (전투·책략 10%, 네잎클로버 효과 중 35%)
| 아이템 | 효과 |
|---|---|
| 천도복숭아 | 먹으면 경험치 +300 (어른은 친밀도 +300) / 관계도에서 선물 → 의형제 |
| 산삼 | 피로도 0 |
| 네잎클로버 | 전투·책략 5번 동안 희귀템 확률 ↑ (전투 버튼이 초록색) |
| 복주머니 | 산삼 · 천도복숭아 · 네잎클로버 중 하나, 가끔 뽑기권 |

### 관계
| 관계 | 내용 |
|---|---|
| 커플 (하트) | 놀기로 하트 4칸 → 고백. 같은 진영은 매번, 다른 진영은 35% 확률로 오름. 둘 다 어른이어야 함. 주군만 애인 여러 명 |
| 의형제 (복숭아) | 천도복숭아 4번 선물 → 의형제 맺기. 한 마리당 최대 3명 |
| 신뢰 (방패) | 정해진 짝. 하트·복숭아가 3칸만 필요. 한 마리당 최대 2명 |
| 가족 (집) | 정해진 짝. 고백(커플) 불가 |
| 앙숙 (해골) | 정해진 짝 + 주군끼리. 놀기·선물·고백 불가. 일부는 어른이 되면 화해 |

## 파일 구조
| 파일 | 역할 |
|---|---|
| `scripts/autoload/game_data.gd` | **숫자·목록은 전부 여기**: 성장 경험치, 피로도, 음식, 드랍률, 장수 목록, 신뢰/가족/앙숙/화해 |
| `scripts/autoload/game_state.gd` | 저장/불러오기 (임시 파일 → 교체, 백업, 값 검사), 뽑기, 호감도, 커플, 의형제, 가방 |
| `scripts/puppy.gd` | 멍냥이 한 마리 진행도 (경험치, 피로도, 친밀도, 음식) |
| `scripts/puppy_view.gd` | 멍냥이 그림 + 쓰다듬기 (하트, 눈 감기, 화남) |
| `scripts/main.gd` | 모든 화면과 창 (코드로 구성) |
| `scripts/celebration.gd` | 성장 폭죽 + 축하 글씨 |
| `scripts/food_icon.gd`, `poly_icon.gd`, `heart_button.gd` | 아이콘 그리기, 관계도 하트 버튼 |
| `assets/dogs/` | 멍냥이 그림 `<id>_<0~2 단계>_<open/closed/half/squint/line 눈>.png` |
| `assets/items/` | 음식·아이템·뽑기 기계 그림 |
| `tools/` | 그림 만드는 파이썬 스크립트 (`dogs.py`, `items.py`, `items2.py`, `gacha_art.py`) — 게임에는 안 들어감 |

## 저장
- `user://save.json` (+ `save.json.bak` 백업). 이 프로젝트는 사용자 폴더 이름을 따로 써서
  Windows에서는 `%APPDATA%\삼국지 강아지 키우기\` 에 저장됨
- 웹에서는 브라우저 저장소(IndexedDB)에 저장
- 초기화: 게임을 끄고 `save.json`에 `{}` 넣고 `.bak` 삭제 (또는 코드에서 `GameState.reset_all()`)
